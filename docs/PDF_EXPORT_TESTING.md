# PDF出力機能 テスト・確認項目

## 基本機能

### ✅ PDF生成
- [ ] ダッシュボードの「PDF出力」ボタンが表示される
- [ ] ボタンをクリックするとPDFが生成される
- [ ] ダウンロードが開始される
- [ ] ファイル名が「スキルシート_{氏名}_{日付}.pdf」形式になっている
- [ ] ローディング状態（スピナー）が表示される
- [ ] 成功時にトーストメッセージが表示される

### ✅ エラーハンドリング
- [ ] 通信エラー時に適切なエラーメッセージが表示される
- [ ] 失敗時にトーストメッセージが表示される
- [ ] エラー後も再試行できる

## データ表示

### ✅ ヘッダー部分
- [ ] 日付が「YYYY年MM月DD日」形式で表示される
- [ ] 「スキルシート」タイトルが中央に表示される

### ✅ 基本情報
- [ ] 氏名が表示される
- [ ] 性別チェックボックス（男 □ 女 □）が表示される
- [ ] 年齢が「{数値}歳」形式で表示される
- [ ] 住所が表示される
- [ ] 未入力項目は空欄または「未設定」と表示される

### ✅ 経歴
- [ ] 最終学歴が表示される
- [ ] 学科が表示される
- [ ] 資格が表示される
- [ ] 複数行の資格が正しく改行される

### ✅ 技術スキル
- [ ] セクション見出し「●技術スキル」が表示される
- [ ] 凡例「◎：応用利用が出来る ○：基本操作可能 △：知識あり」が表示される
- [ ] OS、言語、DBの行が表示される
- [ ] 未入力の場合「未入力」がグレーで表示される

### ✅ 業務実績
- [ ] セクション見出し「●業務実績」が表示される
- [ ] 凡例「要：要件定義 基：基本設計...」が表示される
- [ ] Noが1から順番に表示される
- [ ] 期間が「YYYY/MM」形式で表示される
- [ ] 終了日がない場合「現在」と表示される
- [ ] 業種が表示される
- [ ] お客様名が【】付きで太字表示される
- [ ] システム名が表示される
- [ ] 担当業務が「○要 ○基 ○詳 ○開 ○テ ○運」形式で表示される
- [ ] 開発環境が「、」区切りで表示される
- [ ] 開発言語が「、」区切りで表示される
- [ ] 業務実績が古い順（start_date ASC）に並んでいる
- [ ] 業務実績が0件の場合「業務実績がまだ登録されていません」と表示される

### ✅ 備考
- [ ] セクション見出し「備考」が表示される
- [ ] 備考内容が表示される
- [ ] 複数行の備考が正しく改行される
- [ ] 未入力の場合は空欄で表示される

## レイアウト

### ✅ A4サイズ
- [ ] ページサイズがA4（210mm × 297mm）である
- [ ] マージンが上下左右10mmである
- [ ] 内容が用紙内に収まっている

### ✅ フォント
- [ ] 日本語フォント（Yu Gothic, Meiryo）が使用されている
- [ ] 文字が読みやすいサイズである
- [ ] 文字が崩れていない
- [ ] 文字化けが発生していない

### ✅ テーブル
- [ ] すべてのテーブルに罫線（1px solid #000）が表示される
- [ ] セル内のパディングが適切である
- [ ] ヘッダー行の背景色（#f0f0f0 or #d9d9d9）が表示される
- [ ] テーブルが崩れていない
- [ ] カラム幅が適切である
- [ ] セル内のテキストが適切に配置される（左寄せ/中央寄せ）

### ✅ 複数ページ
- [ ] 業務実績が多い場合、複数ページに分割される
- [ ] ページ分割が適切な位置で行われる
- [ ] テーブル行の途中で改ページされない（page-break-inside: avoid）
- [ ] 各ページのマージンが一定である

### ✅ 色
- [ ] 背景色が正しく表示される（printBackground: true）
- [ ] グレースケール印刷でも読みやすい
- [ ] ヘッダーの背景色が適切である

## デバッグ機能

### ✅ HTMLデバッグ出力
- [ ] `DEBUG_PDF=true` を設定すると HTML が出力される
- [ ] `backend/debug_skillsheet.html` にファイルが作成される
- [ ] ブラウザでHTMLを開いて確認できる
- [ ] HTMLの内容が正しい

### ✅ ログ出力
- [ ] サーバーログに「[PDF Export] Generating PDF for user: {氏名}」が出力される
- [ ] サーバーログに「[PDF Export] Work experiences count: {件数}」が出力される
- [ ] サーバーログに「[PDF Export] PDF generated successfully ({バイト数} bytes)」が出力される
- [ ] エラー時に詳細なエラーログが出力される

## パフォーマンス

### ✅ 生成速度
- [ ] PDF生成が5秒以内に完了する（業務実績10件程度）
- [ ] ローディング状態が適切に表示される
- [ ] ブラウザがフリーズしない

### ✅ ファイルサイズ
- [ ] PDFファイルサイズが適切である（1MB以下が目安）
- [ ] 画像が含まれる場合、適切に圧縮されている

## エッジケース

### ✅ データが空の場合
- [ ] 業務実績が0件でもPDFが生成される
- [ ] プロフィール未入力でもPDFが生成される
- [ ] エラーが発生しない

### ✅ 特殊文字
- [ ] 日本語（ひらがな、カタカナ、漢字）が正しく表示される
- [ ] 記号（□、●、○、/、、など）が正しく表示される
- [ ] 長いテキストが適切に折り返される

### ✅ 大量データ
- [ ] 業務実績が20件以上でも正しく表示される
- [ ] 複数ページに正しく分割される
- [ ] メモリエラーが発生しない

## セキュリティ

### ✅ 認証
- [ ] 未ログイン状態ではPDF出力できない
- [ ] 他のユーザーのPDFは出力できない
- [ ] JWTトークンが適切に検証される

### ✅ データ保護
- [ ] 生成されたHTMLファイルが適切に削除される（デバッグモード以外）
- [ ] 一時ファイルが残らない
- [ ] メモリリークが発生しない

- [ ] ファイル名が正しい
